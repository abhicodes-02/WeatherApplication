# Weather Application 🌦️

A simple weather application that shows real-time weather data using the OpenWeatherMap API.

## 🔧 How to Run the App

1. Download or clone this repository.
2. Unzip if downloaded as a ZIP.
3. Open `index.html` in any modern browser (Chrome, Firefox, Edge, etc.)

## 📁 Project Structure

- `index.html` – Main HTML file
- `style.css` – Styling for the UI
- `script.js` – JavaScript logic and API integration
- `README.md` – Project instructions

## 📝 Notes

- You need a valid OpenWeatherMap API key.
